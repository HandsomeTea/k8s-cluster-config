### 基本流程
1. 创建namespace
2. 部署configmap
3. 部署deployment
4. 部署service
5. 部署ingress

### 开始
1. 创建namespace
```shell
kubectl create namespace dev
```

2. 部署configmap
```shell
kubectl apply -f configmap.yaml -n dev
```

3. 部署deployment
```shell
kubectl apply -f deployment.yaml -n dev
```

4. 部署service
```shell
kubectl apply -f service.yaml -n dev
```

5. 部署ingress
```shell
kubectl apply -f ingress.yaml -n dev
```

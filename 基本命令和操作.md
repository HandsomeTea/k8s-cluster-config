### 查看所有资源信息
- kubectl get all

### namespace
```shell
kubectl get namespace/ns
kubectl create/delete namespace/ns <namespace-name>
kubectl describe namespace/ns <namespace-name>
```

### pod
```shell
kubectl get pod
kubectl delete pod <pod-name> -n <namespace-name>
kubectl describe pod <pod-name> -n <namespace-name>
```

### deployment
```shell
kubectl get deployment
kubectl delete deployment <deployment-name> -n <namespace-name>
# 使用Deployment创建的pod，删除deployment会自动删除其下属的pod
```

### service
```shell
kubectl get service/svc
kubectl delete service/svc <service-name> -n <namespace-name>
kubectl describe service -n <namespace-name>
```

### ingress
```shell
kubectl get ingress
kubectl delete ingress <ingress-name> -n <namespace-name>
kubectl describe ingress <ingress-name> -n <namespace-name>
```

### node
```shell
kubectl get node
kubectl describe node <node-name>
```

### 参数
- `-n`，指定namespace
- `-o` wide，查看详细信息
- `--show-labels`，显示label信息
- `-l app=example`，指定label
- `-A`，查看全部
